Note di rilascio - kDrive 4.1.0

Nuove funzionalità

  • Nuova grafica della pagina Archiviazione con caricamento più fluido e un dettaglio dell'utilizzo del disco più preciso.
  • L'archiviazione kDrive online e le offerte di upgrade sono ora visibili nella pagina Archiviazione.

Correzioni di bug

  • Correzione di sicurezza.
  • Corretto un crash quando la selezione della cartella fallisce; ora viene visualizzato un errore.
  • Corrette le modifiche ai file perse dopo un overflow del monitor delle cartelle.
  • Corretta la gestione delle cancellazioni IPC/TLS.
  • Corretta la gestione delle barre rovesciate nei nomi dei file e nelle risposte del server.
  • Il popup di eliminazione massiva mostra ora il numero reale di eliminazioni.
  • I file possono ora essere idratati mentre la sincronizzazione è in pausa.
  • I messaggi di errore ora vengono conservati quando un'operazione di sincronizzazione viene annullata.
  • Corretto il caricamento dei log al supporto.
  • Corretto un problema di nodi duplicati dopo un nuovo tentativo di caricamento con rinomina.
  • Corretta l'analisi dei nomi di file remoti contenenti virgolette di escape.
  • Corretti gli stati delle caselle di controllo dell'albero delle esclusioni.
  • Corretta la segnalazione dei percorsi remoti degli elementi sincronizzati.
