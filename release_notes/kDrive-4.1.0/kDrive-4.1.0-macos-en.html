Release notes - kDrive 4.1.0

New features

  • The Storage view now displays your kDrive subscription: plan name, files stored online and available space.
  • The mass-deletion confirmation dialog now lists the deleted files.

Bug fixes

  • Security fix.
  • Fixed the display of the blocking "update required" view.
  • Fixed opening local files from the Activities page.
  • Fixed the decoding of drive maintenance states.
  • You are now prompted to log in again when the access token is revoked, instead of seeing an "Access denied" error.
  • Fixed the application exit process.
  • Enforced a minimum window size.
  • Fixed the reported CPU usage.
  • Fixed the conflict-resolution window.
  • Files can now be hydrated while synchronization is paused.
  • Error messages are now preserved when a synchronization operation is canceled.
  • Fixed the upload of support logs.
  • Fixed a duplicate-node issue after a renamed upload retry.
  • Fixed the parsing of remote file names containing escaped quotes.
  • Fixed the checkbox states of the folder exclusion tree.
  • Fixed incorrect remote paths reported for synchronized items.
