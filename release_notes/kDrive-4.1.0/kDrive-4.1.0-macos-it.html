Note di rilascio - kDrive 4.1.0

Nuove funzionalità

  • La vista Archiviazione mostra ora l'abbonamento kDrive: nome dell'offerta, file archiviati online e spazio disponibile.
  • La finestra di conferma dell'eliminazione massiva elenca ora i file eliminati.

Correzioni di bug

  • Correzione di sicurezza.
  • Corretta la visualizzazione della vista di blocco che richiede un aggiornamento.
  • Corretta l'apertura dei file locali dalla pagina Attività.
  • Corretta la decodifica degli stati di manutenzione di un drive.
  • Ora viene richiesto di effettuare di nuovo l'accesso quando il token di accesso viene revocato, invece di vedere un errore di accesso negato.
  • Corretto il processo di chiusura dell'applicazione.
  • Ora viene applicata una dimensione minima della finestra.
  • Corretto l'utilizzo della CPU segnalato.
  • Corretta la finestra di risoluzione dei conflitti.
  • I file possono ora essere idratati mentre la sincronizzazione è in pausa.
  • I messaggi di errore ora vengono conservati quando un'operazione di sincronizzazione viene annullata.
  • Corretto il caricamento dei log al supporto.
  • Corretto un problema di nodi duplicati dopo un nuovo tentativo di caricamento con rinomina.
  • Corretta l'analisi dei nomi di file remoti contenenti virgolette di escape.
  • Corretti gli stati delle caselle di controllo dell'albero delle esclusioni.
  • Corretta la segnalazione dei percorsi remoti degli elementi sincronizzati.
