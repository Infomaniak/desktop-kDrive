Note di rilascio - kDrive 4.1.0

Nuove funzionalità

  • Migrazione alla nuova versione dell'API di kDrive (v3), per migliorare le prestazioni e l'affidabilità della sincronizzazione.
  • Migliorata la visualizzazione delle date nella vista delle attività.

Correzioni di bug

  • Miglioramenti alla sicurezza.
  • Risolto un problema che causava il blocco prolungato della sincronizzazione a seguito di un errore di rete.
  • Risolto un problema per cui l'applicazione poteva non avviarsi automaticamente al login.
  • Risolti gli errori di sincronizzazione causati da file di alias danneggiati.
  • Risolto un problema per cui l'opzione "Chiedi prima di eliminare" non veniva salvata correttamente.
