Release notes - kDrive 4.1.0

What's new

  • The Storage view now shows the space included in your plan.
  • When deleting a large number of files, kDrive shows you the list of affected items before you confirm.
  • The activity feed clearly shows the type of each action (added, modified, deleted…) with easier-to-read dates.
  • Search displays more results and directly opens files already on your computer.
  • The tooltip of the kDrive icon in the notification area shows the status of each of your synchronizations.
  • Smarter synchronization: a file is only uploaded or downloaded if its content has actually changed, and no longer each time its date is modified. Fewer unnecessary transfers, more speed.
  • When a file is saved in several steps, kDrive waits a little longer before synchronizing it to avoid unnecessary transfers.
  • kDrive now uses the new version of the Infomaniak API for more stable synchronization.

Improvements and fixes

  • Improved reliability of the Lite Sync option.
  • Stronger protection against unwanted file deletions.
  • Several bug fixes and stability improvements.
