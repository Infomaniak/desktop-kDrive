Release notes - kDrive 4.1.0

New features

  • New Storage page design with smoother loading and a detailed breakdown of disk usage.
  • Your online kDrive storage and upgrade offers are now visible in the Storage page.

Bug fixes

  • Security fix.
  • Fixed a crash when the folder picker fails; an error is now displayed.
  • Fixed file changes being missed after a folder-watcher overflow.
  • Fixed the handling of IPC/TLS cancellations.
  • Fixed backslash handling in file names and server replies.
  • The mass-deletion popup now displays the real number of deletions.
  • Files can now be hydrated while synchronization is paused.
  • Error messages are now preserved when a synchronization operation is canceled.
  • Fixed the upload of support logs.
  • Fixed a duplicate-node issue after a renamed upload retry.
  • Fixed the parsing of remote file names containing escaped quotes.
  • Fixed the checkbox states of the folder exclusion tree.
  • Fixed incorrect remote paths reported for synchronized items.
