Versionshinweise – kDrive 4.1.0

Neue Funktionen

  • Umstellung auf die neue Version der kDrive-API (v3) für eine verbesserte Synchronisationsleistung und -zuverlässigkeit.

Fehlerbehebungen

  • Sicherheitsverbesserungen.
  • Es wurde ein Problem behoben, durch das die Synchronisierung nach einem Netzwerkfehler zu lange angehalten blieb.
  • Der vom Installationsprogramm nach einer erfolgreichen Installation zurückgegebene Fehlercode wurde korrigiert.
  • Die Darstellung der Taskleistensymbole wurde korrigiert.
  • Es wurden mehrere Abstürze behoben.
  • Ein Fehler in der Auswahl der auszuschließenden Ordner wurde behoben, der auftrat, wenn der Zugriff auf einen Ordner verweigert wurde.
