Release notes - kDrive 4.1.0

New features

  • Migration to the new version of the kDrive API (v3), for improved synchronization performance and reliability.
  • Improved the display of dates in the activity view.

Bug fixes

  • Security improvements.
  • Fixed an issue that caused the synchronization to remain paused for too long after a network error.
  • Fixed an issue where the application could fail to start automatically at login.
  • Fixed synchronization errors caused by corrupted alias files.
  • Fixed an issue where the "Ask before deleting" option was not saved correctly.
