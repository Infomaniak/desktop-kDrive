Release notes - kDrive 3.9.0

Bug fixes

  • Security fix.
  • Fixed missed file changes after an inotify event overflow.
  • Fixed a synchronization loop that could occur after renaming a folder.
  • Fixed synchronization loops in the update detection.
  • Improved the handling of symbolic links.
  • Fixed moving items under a folder link.
  • Fixed a synchronization issue with complex operation sequences.
  • Fixed a synchronization issue with move conflicts.
  • Improved the retry of failed requests after temporary server errors.
  • Fixed a crash that could occur when deleting a synchronization.
  • Fixed errors during the creation of a synchronization.
  • Fixed database locking errors.
  • Fixed stale synchronization errors that were never cleared.
  • Error messages are now preserved when a synchronization operation is canceled.
  • Fixed the upload of support logs.
  • Fixed a duplicate-node issue after a renamed upload retry.
  • Fixed the parsing of remote file names containing escaped quotes.
  • Links are no longer opened from the search bar.
  • Fixed the pause duration that kept increasing after repeated network errors.
  • Fixed the checkbox states of the folder exclusion tree.
  • Fixed the detection of the application installation directory.
  • Various bug fixes.
