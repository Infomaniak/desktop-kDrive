Release notes - kDrive 3.8.9

Bug fixes

  • Security fix.
  • Fixed a synchronization loop that could occur after renaming a folder.
  • Fixed synchronization loops in the update detection.
  • Improved the handling of symbolic links.
  • Fixed moving items under a folder link.
  • Fixed a synchronization issue with complex operation sequences.
  • Fixed a synchronization issue with move conflicts.
  • Improved the retry of failed requests after temporary server errors.
  • Fixed an error that could occur when the user avatar was missing.
  • Links are no longer opened from the search bar.
  • Fixed a crash that could occur when quitting the application.
  • Various bug fixes.
