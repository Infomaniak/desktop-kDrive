# Security Policy

We take security seriously and appreciate responsible disclosure.

If you believe you have found a security vulnerability in this project, please report it privately through the official Infomaniak bug bounty program:

https://yeswehack.com/programs/infomaniak-bug-bounty-program

Please do not open a public GitHub issue for security vulnerabilities.

## Reporting requirements

Before submitting a report, please review the bug bounty program's scope, exclusions, and submission requirements. Scope exceptions and eligibility rules are defined by the program itself, and reports must follow those requirements.

When reporting, include:
- a clear description of the issue
- affected component or version
- steps to reproduce
- potential impact
- any proof of concept or sample payload if available

## Responsible disclosure

Please:
- do not access or modify user data beyond what is necessary to validate the issue
- avoid privacy violations, service disruption, or destructive testing
- stop once the issue is confirmed
- keep the report confidential until it has been assessed and addressed

We appreciate coordinated disclosure and will do our best to investigate and remediate valid reports promptly.
