# Generated Lottie Animations

The Lottie sources are supplied locally and are not versioned; only the generated QML components are tracked, in each
window's `animations/` directory. They carry a generated-file header and are excluded from `qmllint`.

## Rules

- Regenerate a defective animation from its source and fix the defect in the generation steps below. Edit neither the
  generated geometry or timing nor the screens that host the animation.
- Use `lottietoqml` generated QML: `Qt.labs.lottieqt` renders Lottie JSON only, not `.lottie` zip containers.
- Generate without the curve renderer (no `-c`): it distorts dashed strokes and moving dots on GPU (Mesa Intel, native
  Wayland). The offscreen platform hides the defect, so check animations in a real window.
- The geometry renderer draws paths without antialiasing: the container renders the animation in a multisampled layer
  (`layer.enabled`, `layer.samples` from the tokens, `layer.smooth`).
- Generated QML imports `QtQuick.Timeline`: the Conan Qt package must provide `qtquicktimeline`.
- When Light and Dark share the same geometry, keep one generated component and bind every non-transparent color to
  `IKColors`. Take a state's palette only from that state's Light/Dark assets.
- `LoaderStrokeAnimation` serves both themes, with its front page drawn as a 1.25 px outline.
- Instantiate a finite status animation only while its state is active, so it starts when the status becomes visible.

## Procedure

Use the `lottietoqml` of the Conan Qt package (`source build-linux/build/build/Debug/generators/conanrun.sh`). For each
animation:

1. Take the animation payload: the `.json` of a `.lottie` container other than `manifest.json`.
2. Normalize it:
    - Remove `h` from the keyframes of animated shape paths (`ty == "sh"`, `ks.a == 1`): `lottietoqml` leaves such a path
      empty (`PathSvg { path: "M 0 0 " }`).
    - When a fill spans outer and inner contours and the output emits one filled `ShapePath` per contour, combine each
      outer contour with its reversed inner contour so the holes survive.
    - For the loader, replace the `page-front` shapes with their first path plus their last item turned into a stroke
      (`ty: "st"`, `w: 1.25`, `lc: 2`, `lj: 2`, `ml: 4`, without `r`).
3. Run `lottietoqml <normalized>.json <output>.qml`, without `-c` / `-p`, and check that the output has no
   `PathSvg { path: "M 0 0 " }`.
4. Change the root `visible: frameCounter >= 0 && frameCounter < <end frame>` to `<=`: `lottietoqml` hides the root on
   the last frame, so a finished animation would disappear and a looping one would blink once per loop.
5. Prepend the repository QML license block, then `// Generated by lottietoqml. Do not edit geometry or timing
   manually.` and `// Generated from Lottie file <normalized file name>`.
6. For Home animations, replace each generated color with `IKColors.home<State>*` per the list above, add
   `// Palette bindings use IKColors for automatic Light/Dark adaptation.` to the header and `import kDrive.UI`.

Compare each regenerated animation with the previous one in a real window, in both themes, before committing.
